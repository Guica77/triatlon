# Environments, Activation Setup, and Handoff-Doc Mode

Load this for setup questions, compaction/resume behaviour, or when running in an environment without filesystem access.

## Recommended activation setup

At the start of any task-oriented session — any interaction where tools will be used and deliverables produced — invoke the task-observer skill before beginning work.

When loading any skill, check the observation log for OPEN observations tagged to that skill and apply relevant insights to the current work.

## Compaction behaviour

When context compacts mid-task, the project activation instruction should cause the resumed session to read this observer again. Observations before and after compaction append to the same stable log with continuous numbering.

## Handoff-doc mode

Without persistent filesystem access, collect observations in-session and deliver a structured handoff document containing decisions, observations, principles, action items, and working artifacts.
