# Comprehensive Review

Use this procedure for a scheduled or explicitly requested observer review.

1. Read and classify every observation from the live log. Entries without a status are OPEN.
2. Read active cross-cutting principles.
3. Cross-check each OPEN observation against the available skills.
4. In an interactive session, present proposed changes and wait for approval.
5. Stage approved skill changes; do not modify live skills directly.
6. Mark applied observations with a dated ACTIONED status and update the review timestamp.
7. Report updated, skipped, and escalated items.

Do not create new skills during a review without the user's explicit approval. Preserve attribution, licensing, confidentiality, and enforcement rules. If an observation is uncertain or requires restructuring, escalate it rather than applying it automatically.
